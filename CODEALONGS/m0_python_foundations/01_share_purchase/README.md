# M0.1.2 — One Share Purchase

This folder is the teaching pair for M0 Section 1.

1. `01_purchase_cost.py` is the live cookbook snippet. It teaches only
   variables and arithmetic: shares × historical price, then cash remaining.
2. `02_purchase_cost_code_along.ipynb` begins with that exact snippet and
   gradually adds current value, a second purchase, dictionaries, loops, and
   a function through prediction and "your turn" prompts.

Run the snippet from `CODEALONGS/`:

```bash
uv run python m0_python_foundations/01_share_purchase/01_purchase_cost.py
uv run jupyter lab
```
