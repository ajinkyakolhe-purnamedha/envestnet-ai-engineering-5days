# M7 Code-Alongs: Agentic LLMs By Hand

Run from the repository root:

```bash
uv run --project CODEALONGS python CODEALONGS/m7_agentic_applications/01_regular_vs_agentic_llm.py
```

Snippets:

- `01_regular_vs_agentic_llm.py` - why agentic LLMs are different from regular LLM/RAG calls
- `02_functions_as_tools.py` - Python functions as model-visible capabilities
- `03_llm_tool_request.py` - offline SmolLM attempting a tool request as structured text; invalid JSON is blocked and shown
- `04_python_dispatch.py` - validation and dispatch in Python
- `05_react_loop.py` - ReAct loop with observations and `max_turns`
- `06_framework_mapping.py` - how the same parts show up in smolagents and LlamaIndex
