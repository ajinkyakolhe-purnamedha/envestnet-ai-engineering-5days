# Checkpoint Lab · Build the Chronos Advisor

**Timebox: 60 minutes.** Build one small educational investor assistant for
Alice. It must combine a local LLM chat, retrieved policy evidence, and one
bounded agent. The three completed code cards beside this lab are reference
snapshots, not the answer to this integration exercise.

## Scenario

Alice asks: *“What does the policy say about my concentration risk?”* Your
assistant may use Alice's supplied demo portfolio and the supplied investment
policy. It is educational only: it cannot trade, use another client’s data, or
invent a policy rule that retrieval did not find.

## What you will build

Complete the three `TODO`s in [starter.py](starter.py):

1. Build safe local-chat messages from trusted Alice facts and recent history.
2. Load the policy, build a LlamaIndex query engine, and retrieve evidence.
3. Turn that engine into a tool, then expose it and the portfolio function to
   one `ToolCallingAgent`, bounded to three steps.

`classroom_model.py` is supplied setup. It is an explicitly mocked model
tool-call response so this lab is reliable with the 135M offline model. Your
chat and RAG calls remain real local model calls.

## Suggested pace

| Minutes | Work |
| ---: | --- |
| 0–10 | Run and read code cards `01`–`03`; identify chat, evidence, and tool seams. |
| 10–20 | Complete TODO 1 and confirm **Checkpoint 1** prints local chat. |
| 20–35 | Complete TODOs 2a–2b and confirm **Checkpoint 2** prints evidence. |
| 35–55 | Complete TODOs 3a–3b and inspect the **Checkpoint 3** agent trace. |
| 55–60 | Check the boundaries and write one reflection. |

## Run

From `CODEALONGS/`:

```bash
uv run --extra courseware python checkpoint_chronos_advisor/lab/starter.py
```

Use [hints.md](hints.md) only when you are stuck. Do not look for a solution
inside `CODEALONGS`: the instructor keeps that separately.

## Done means

- The local chat receives trusted Alice facts and only the most recent history.
- The policy engine retrieves evidence that includes the **35%** concentration limit.
- The agent trace calls the Alice-only portfolio tool and the policy RAG tool.
- The agent has `max_steps=3`; a request for another client returns access denied.

## Optional extension

After the core lab works, ask for `bob` instead of `alice`, then change the
policy query. What boundary blocks Bob’s data? Is the response grounded in the
retrieved evidence?

## Reflection

Which part of this assistant is generated by a model, and which part is
ordinary deterministic application code? Why is an allowlist stronger than a
prompt instruction alone?
