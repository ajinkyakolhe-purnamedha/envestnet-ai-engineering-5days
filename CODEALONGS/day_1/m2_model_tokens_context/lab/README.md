# M2 Lab · Instrument the Chronos Portfolio Assistant

Timebox: 60–90 minutes. Extend the M1 assistant idea; do not build a new chat
application and do not make a provider call in your tests.

1. Run `mini_lab.py` and explain its three measurements.
2. Complete `starter.py`: cost estimate, valid history trimming, and cumulative cost.
3. Add a short synthetic transcript and demonstrate what the assistant forgets
   after trimming.
4. Record one quality/cost/latency observation. Use supplied usage metadata,
   not a claim about a current provider price.

Success: a reviewer can inspect the token/cost figures, see a valid retained
transcript, and reproduce the result offline. `solution.py` is **Instructor only:** after learners have attempted the starter.
