# M3 Lab · Pattern selection clinic

This 60–90 minute lab turns candidate ideas into an explainable application
decision. Start with `mini_lab.md`; then complete the table and one small
implementation described in `starter.md`. `instructor_solution.md` is
**Instructor only:** until groups have made and defended their choices.

Success means each decision names the needed data boundary, the least complex
pattern, why a simpler pattern fails, and one deterministic first test.
