# M3 answer key

1. A — Separation creates diagnosable, independently changeable inputs.
2. A — Requirements and boundaries determine the solution.
3. A — A direct call is the first pattern.
4. A — Structured output supports predictable downstream handling.
5. A — Retrieval is justified by missing private/current/external information.
6. A — Fine-tuning changes behavior/style; retrieval supplies runtime knowledge.
7. A — Agents earn complexity for dynamic multi-step tool work.
8. A — Shape validation and policy validation are separate responsibilities.
9. A — Model/deployment choices create capability and operating trade-offs.
10. A — Use the least-complex reliable pattern and document the decision.
11. The order encodes priority: if dynamic steps are required, an agent may be necessary even though the task also needs a format. The selector should reflect the intended capability hierarchy and be tested for overlaps.
12. Run deterministic business-policy validation and reject or route for approval before any action.
13. Extra latency/cost, irrelevant retrieved context, retrieval failure, or conflicting facts.
14. Direct call; structured output; retrieval; agentic workflow. Each is the first pattern matching the stated capability.
15. Example: prompted structured output with a fast/default model for extraction and policy validation; reject a direct-call-only approach if typed fields are needed; enforce allocation/risk limits deterministically before approval.
