# M9 · Finishing agentic applications quiz

**Ten questions, one per essential idea in the module.**

Every option is a true statement from the course. Only the option that answers
the question asked is correct. Some questions have more than one right answer;
each of those says so.

---

1. A user asks a follow-up that only makes sense with the previous turn. What is missing?
   - A. Draft verification.
   - B. Conversation memory.
   - C. Token streaming.
   - D. Policy RAG.

2. A developer says, "The model remembers now." What is the correction?
   - A. Memory is written into model weights.
   - B. Memory is the approved note row.
   - C. Memory is the audit trace.
   - D. Memory is transcript sent again.

3. **Select two.** Why bound memory before routing or drafting?
   - A. Transcript tokens cost money.
   - B. Old turns may exceed scope.
   - C. Models can then run tools directly.
   - D. Summaries keep every figure exact.

4. The user asks, "What is the concentration rule?" Then, "Why is that a problem for Alice?" What should routing use?
   - A. The latest question only.
   - B. The previous full answer only.
   - C. Scoped history plus latest turn.
   - D. Summaries from every client.

5. A rule checker verifies word count and threshold citations. Which rung is that?
   - A. The final human approval rung.
   - B. Optional once a judge exists.
   - C. Cheap deterministic first rung.
   - D. A replacement for trace logs.

6. A model judge says "YES" on weak notes. What should happen?
   - A. Give it veto power.
   - B. Fine-tune the workflow.
   - C. Remove deterministic checks.
   - D. Keep it advisory and measure it.

7. **Select two.** Which two describe the human gate?
   - A. Client-facing content starts pending.
   - B. Rejection keeps it invisible.
   - C. The judge decides final visibility.
   - D. The model can approve passing drafts.

8. Pending drafts survive an API restart. What made that possible?
   - A. Memory lives in hidden model state.
   - B. Tokens stream to the UI.
   - C. Drafts are durable rows.
   - D. Old answers go into the vector index.

9. A draft is already approved. Someone tries to reject it later. What should happen?
   - A. The latest human decision wins.
   - B. Add a second approved row.
   - C. Ask the model judge to decide.
   - D. Reject the change.

10. A fact-grounded answer is not enough. What else must the trace support?
    - A. Hardware and framework metadata.
    - B. Replay of route, facts, checks, judge, decision.
    - C. User satisfaction and release ownership.
    - D. Chunks, embeddings, citations, and recall.
